# Security

The current development version is supported; fixes are applied to `main`. Roveran processes user-controlled image and project files in a browser, so malformed imports, dependency issues and browser resource exhaustion matter even though it has no accounts or backend.

After the public repository is created, use its **Security → Report a vulnerability** feature when private reporting is enabled. Otherwise contact a maintainer privately through the contact method on their repository profile. Do not publish a working exploit, private image or sensitive project in an issue. Include affected versions, browser details, impact and a minimal nonprivate reproduction.

For ordinary rendering or workflow bugs without sensitive impact, use the bug report form. Do not commit credentials or add telemetry/image uploads as part of a security fix. The maintainer will coordinate disclosure after a fix is available; no response-time guarantee is offered.

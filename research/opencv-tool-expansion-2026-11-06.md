# OpenCV WebLab tool expansion

The [October review](opencv-tool-expansion-2026-10-31.md) led to ten tools that are already in the catalog. The next selection prioritizes distinct workflows students can build with the still-image graph. Direct calls confirmed that the bundled OpenCV.js 4.13.0 build exposes the core APIs for all five.

| Tool              | Why it belongs                                                                                                                                                                                                                                                                                                                                               |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Template matching | Connect a Crop branch to a larger search image and see where a patch fits. Squared difference gives an interpretable score and its minimum locates the best match. A single annotated image fits the existing preview and export workflow. [OpenCV object detection API](https://docs.opencv.org/4.13.0/df/dfb/group__imgproc__object.html)                  |
| Inpaint           | Use a thresholded defect mask for restoration. OpenCV offers Telea and Navier–Stokes reconstruction, both of which use neighboring pixels. The app processes RGBA as RGB and restores the original alpha. [OpenCV inpainting API](https://docs.opencv.org/4.13.0/d7/d8b/group__photo__inpaint.html)                                                          |
| Flood selection   | Build a seed-based mask that illustrates the difference between intensity thresholding and connectivity. Fixed-range mode compares candidates with the seed, and mask-only mode leaves the input available to other branches. [OpenCV flood fill API](https://docs.opencv.org/4.13.0/d7/d1b/group__imgproc__misc.html)                                       |
| Pad image         | Compare constant, repeated, and reflected borders before running filters. The added pixels become part of the graph image and can be inspected directly. [OpenCV border tutorial](https://docs.opencv.org/4.13.0/dc/da3/tutorial_copyMakeBorder.html)                                                                                                        |
| Fourier spectrum  | Introduce frequency analysis through a centered, normalized display of log magnitude. Zero padding to efficient DFT sizes allows odd and prime-sized inputs. [OpenCV DFT tutorial](https://docs.opencv.org/4.13.0/d8/d01/tutorial_discrete_fourier_transform.html), [OpenCV array operations](https://docs.opencv.org/4.13.0/d2/de8/group__core__array.html) |

The selection favors tools that expose a new concept through existing image ports and controls. GrabCut and watershed are candidates for a separate segmentation lesson because their region or marker inputs need their own teaching workflow. [OpenCV GrabCut guide](https://docs.opencv.org/4.13.0/dd/dfc/tutorial_js_grabcut.html), [OpenCV watershed guide](https://docs.opencv.org/4.13.0/d2/dbd/tutorial_distance_transform.html)

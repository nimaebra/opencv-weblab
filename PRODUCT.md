# Roveran

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Confirmed: React, Vite, TypeScript, React Flow, Zustand, Tailwind CSS and Radix primitives; IndexedDB, fflate, Dagre and Vite PWA; Node 24 for development/building, pnpm and Turborepo. Static deployment, no server API.

## Users

University students and developers learning image processing on laptops and desktops.

## Product Purpose

Arrange OpenCV operations as a graph, adjust parameters, and inspect automatically updated intermediate images without writing or rerunning code.

## Operating Context

Preview-first lab: searchable library left, comparison above the graph, parameters and explanations right. Desktop resizable panels; smaller-screen panel navigation.

## Capabilities and Constraints

37 processing tools plus image sources, multiple still-image inputs, branches and merges, Python/JSON/PNG and full-resolution measurement CSV export and portable backups including originals. Projects autosave on this device. Production supports offline reopening and controlled updates. Connected components, external contour measurements, area filtering and heterogeneous image/mask inputs extend segmentation into object analysis. Viewer includes pixel inspection, histograms, true-size zoom and optional grayscale kernel calculations. Thirteen guided experiments include hints and local learner-confirmed progress. Three-value parameter comparisons use the same input and apply as one undoable edit. Graph edits are atomic and undoable. No generative AI, camera/video, public sharing or collaboration.

## Brand Commitments

Roveran is the project name. The user approved the preview-first lab layout and requested a strong, responsive UI.

## Evidence on Hand

References: michaelgallacher/opencv-pipeline and cpvrlab/ImagePlay for interaction ideas. Empty initial workspace; no existing brand assets or claims.

## Product Principles

- Show the effect of an operation and explain its parameters.
- Keep the editor responsive while processing.
- Make graphs reproducible and exportable.
- Keep the full learning lab useful without accounts or a backend.
- Keep source images and projects on the device.
- Teach input/output contracts and expose reproducible Python.
- Prioritize learning rather than industrial operational requirements.

## Accessibility & Inclusion

Keyboard alternatives to dragging and connecting, explicit input labels, visible focus, accessible status messages, and responsive panels.
